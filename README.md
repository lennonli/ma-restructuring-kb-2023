# 并购重组审核案例法律问题案例库 · 2023年度

本库回溯 2023 年取得注册批复、注册生效的重大资产重组案例 **7 家**：上交所主板 5 家、科创板 2 家。案例涵盖发行股份购买资产、发行股份及支付现金购买资产、重组上市及吸收合并等交易安排，具体以各案公开披露材料为准。

> 内容基于公开披露文件提炼，仅供内部研究与执业参考，不构成法律意见。对于源文件未载明的注册批复文号、交割结果或其他事实，保留“待核验”边界，不作推测填充。同步展示于 `https://ai.licheng.uk/ma2023/`。

## 快速使用

```bash

grep -l "业绩承诺\|关联交易\|重组上市" cases/*.md

# 按结构化元数据筛选支付方式或交易金额
python3 -c "import json;[print(x['file'],x['pay_method'],x['deal_amount']) for x in json.load(open('scripts/index.json')) if x['pay_method']=='混合']"

# 修改案例 frontmatter 后重建索引
python3 scripts/build-index.py
```

- **年度总结**：`reports/2023年度总结.md`，归纳 7 家案例的共性法律问题、监管趋势及分案例索引。
- **AI 智能体**：本仓库为纯 Markdown；ZCode / Claude Code / Codex 本地 clone 后可直接检索正文和 `scripts/index.json`。

## 核心材料范围

每份案例围绕三类核心文件提炼：

1. **重大资产重组报告书（草案）及其修订稿/最终稿**：交易方案、标的资产、评估定价、支付方式、募集配套资金和整合安排。
2. **交易所并购重组审核问询函及上市公司、独立财务顾问等回复文件**：监管问题、回复论证和中介核查程序。
3. **法律意见书及补充法律意见书**：主体资格、协议与程序、资产权属、合规经营、关联交易、同业竞争、诉讼处罚等律师核查结论。

必要时结合会计师事务所、评估机构等专项回复；源材料缺失或为扫描版的部分在正文中标注“待核验”。

## frontmatter 字段规范

IPO 年度库通用字段继续保留：

- `company` 公司全称；`short` 文件名中的简称；`code` 六位证券代码（字符串）；`board` 使用六值口径：科创板｜沪市主板｜深市主板｜深市创业板｜北交所｜新三板。
- `layer`、`listing_date`、`inquiry_rounds`、`cutoff_date`、`tags`：对本库不适用或源材料未载明的留空，不由交易安排推测。
- `lawyer` 发行人/上市公司律师；源材料未载明时留空。

并购重组字段：

- `deal_type`：交易方案类型，例如发行股份购买资产、发行股份及支付现金购买资产并募集配套资金等，保留源材料口径。
- `pay_method`：支付方式结构化字段，本年度源材料归一为 `发股` 或 `混合`；不根据交易金额反推。
- `deal_amount`：交易金额结构化字段，数值单位统一为 **万元**；金额以源案例 frontmatter 为准，保留小数精度。
- `status`：注册状态，本库 7 家均为 `注册生效`。
- `registered_date`：取得注册批复/注册生效日期，按 `YYYY-MM-DD` 保存。
- `fin_adv`：独立财务顾问/财务顾问机构。
